Small browser,
serious privacy.

Kiwi is a privacy-first web browser built on the Mustela engine (WebKitGTK). Tracking domains are refused through a local proxy with DoH, fingerprint surfaces are switches instead of promises, and every site can carry its own rules.

Download for Linux View source

What Kiwi does

Local proxy network layer

A loopback proxy inside the engine enforces the tracking blocklist at connection level, resolves names through DNS-over-HTTPS (fail-closed) and chains upstream proxies when configured.

Per-site rules

JavaScript, cookies, fingerprinting, permissions, zoom, user agent and CSS — per host, edited in the built-in Privacy Center with visual indicators.

Fingerprint switches

Canvas readback, WebGL, remote fonts and referrer trimming are hard switches applied through content filters and user scripts — no promises, just blocked surfaces.

Profiles and libraries

Isolated profiles with their own history, bookmarks, autofill and storage; a bookmarks manager, search engine editor with !keyword shortcuts.

Engine privacy by default

Global Privacy Control (JS + Sec-GPC header), tracker blocklist compiled into content filters, branded error pages, private tabs that never touch disk.

Material Design 3, pastel peach

Solid fills, 1px outlines, radius 8, no gradients, no shadows, no blur — a calm interface that stays out of the way.
